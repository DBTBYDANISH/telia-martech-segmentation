# Reporting role

[create_reporting_role.sql](create_reporting_role.sql) creates `MARTECH_REPORTING_RO`, a read-only Snowflake role for the schemas generated by this dbt project.

It grants:

- Database usage on `MARTECH_DB`
- Schema usage on `MARTECH_DB.STAGING`
- Schema usage on `MARTECH_DB.STAGING_STAGING`
- `SELECT` on existing and future tables, views, and materialized views

The script does not assign the role to a person and does not grant warehouse access automatically. Uncomment and customize the final commands for the BI service account and warehouse.

Run it as `SECURITYADMIN` or another role with the required grant privileges. Confirm the schema names with `dbt ls --output json` if the dbt target schema changes.
